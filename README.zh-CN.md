# doc-consistency · 长文档一致性体检

**把「这份文档跟它自己一不一致」变成一件可以按按钮复查的事。**

[English](README.md) · MIT · Node ≥ 18 · **不联网、不上传、不调模型、零依赖**

---

写不难，难的是写完之后。

正文写「见图 3-12」，合稿时那张图丢了；附件编号从 5 跳到 7，目录和正文对不上；
第二章叫「用户」，第五章叫「客户」；三个人各写一份合并成一份，丢了谁的哪一段没人知道；
去年的标书复制过来，忘了改项目名和日期。

这些错的共同点是：**随篇幅指数增长，而人的注意力随篇幅衰减。**
一份 300 页的文件，人通读要两天，且两遍会看漏不一样的地方；
机器跑一遍几十秒，跑十遍结果一模一样。

## 安装

```bash
npx skills add dongsheng123132/doc-consistency
```

或者直接 clone 下来跑 —— **没有任何依赖要装**：

```bash
node scripts/check.mjs <文件或目录…>
```

## 用

```bash
# 单文件
node scripts/check.mjs 教材终稿.docx

# 多人分头写的整目录
node scripts/check.mjs ./书稿/ --all

# 合稿丢了什么
node scripts/check.mjs 合并稿.docx --baseline ./分册/

# 投标前卡一道，还有高危项就不许提交
node scripts/check.mjs 投标文件.docx --fail-on high
```

| 选项 | 作用 |
| --- | --- |
| `--all` | 列出全部红点（默认只列前 20 条，汇总始终完整） |
| `--limit <n>` | 清单条数上限 |
| `--json` | 完整 JSON，不截断 —— 给 CI 和后续流程用 |
| `--glossary <file>` | 术语表，每行 `正名 = 变体1, 变体2` |
| `--baseline <路径…>` | 基准稿，用于合稿丢段比对 |
| `--fail-on high\|medium\|low` | 到该级别退出码为 1 |
| `--lang zh\|en` | 报告语言 |

支持 `.docx` / `.md` / `.txt`。位置报成 `¶41`（docx 第 41 段）或 `L17`（第 17 行），**每条都能翻回去看**。

## 查什么

| 规则 | 抓的是 |
| --- | --- |
| **交叉引用悬空** | 正文写「见图 3-12」，但那张图既没题注也不在目录里 |
| **编号重号 / 跳号 / 起始异常** | 图、表、公式、附录序列断了或重了 |
| **目录 ↔ 正文对账** | 目录列了正文没有（读者翻空）／正文有目录漏了 |
| **章节引用悬空** | 「详见第 7 章」，但没有第 7 章 |
| **章节骨架缺项** | 多数章都有「学习目标」，某一章没有 |
| **术语写法不一致** | `AI Agent` / `AI agent` / `AI-Agent` 混用；或违反你给的术语表 |
| **占位符残留** | `TODO`、`TBD`、待填、`×××公司`、Lorem ipsum |
| **疑似旧版年份** | 全文主用 2026，某处冒出 2023 且挨着「合同 / 截止 / 项目」 |
| **标题重复** | 同级标题重名，目录里并成两条一样的 |
| **合稿疑似丢段** | 基准稿里有、当前稿里没有（需 `--baseline`） |

## 最要紧的是这一段

每份报告结尾都有**可重跑的复查块**：

```bash
node check.mjs 投标文件.docx
node check.mjs 投标文件.docx --fail-on high   # 还有高危项就返回非 0
```

这是本工具跟「我帮你看了一遍，没问题」的根本区别。

不是「我检查过了」，是「**您自己跑一遍，红点从 137 条降到 0**」——
验收标准可以写进合同，而且是机器能判定的，省掉扯皮。

## 边界老实说清楚

- **Word 自动编号和自动题注是「域」，不落在正文文字里，本工具读不到。**
  遇到这种文档会明确报「题注不在文字层」，并写明
  ——「**这一项查不了，不代表没问题**」。不会替你打包票。
- **语义级的术语归并**（「用户」和「客户」是不是同一个概念）需要模型判断，
  本工具不做，只做写法层面的确定性检查。
- 查的是「文档跟自己一致」，**不是**「内容正确」。这两件事不要混。
- 不出具法律意见、不做技术判断、不保证过审。

## 隐私

全程在你自己的机器上跑。**不联网、不上报、不上传、不调用任何模型 API。**
你的文档没有离开过这台电脑 —— 未出版的书稿、未开标的投标文件、客户合同，这一点很重要。

不用信我们：全部代码约 600 行零依赖 JavaScript，只用了 `node:fs` / `node:path` / `node:zlib`，自己翻。
